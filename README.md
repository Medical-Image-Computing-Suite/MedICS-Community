# MedICS Community

Home for community documentation and shared resources around the
[Medical Image Computing Suite (MedICS)](https://github.com/Medical-Image-Computing-Suite/MedICS).

## Wiki

The **MedICS main application** user / developer wiki lives here:

- **Browse online:** [MedICS-Community Wiki](https://github.com/Medical-Image-Computing-Suite/MedICS-Community/wiki)
- **Source Markdown:** [`wiki/`](wiki/) (synced to GitHub Wiki via [Sync Wiki](.github/workflows/sync-wiki.yml))

Current wiki version covers install, UI, workspace / `MedImage`, toolboxes, extensions, configuration, architecture, CLI, and events. **Auth / license / payment topics are intentionally omitted.**

### Enable the GitHub Wiki (maintainers)

1. Repo **Settings → Features → Wikis** → enable.
2. Create any first page in the GitHub UI (creates `.wiki.git`).
3. Push updates to `wiki/` on `main`, or run `scripts/sync-wiki.sh`.
